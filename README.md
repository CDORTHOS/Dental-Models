# Dental-Models

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Open-source Python tool for generating solid, table-stable bases for dental model shells. Three-click occlusal orientation, skirt generation, filename embossing, watertight boolean merge, and per-case parameter logging. Built for dental labs working with 3D-printed models.
